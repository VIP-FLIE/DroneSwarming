# macOS

The project does not maintain a macOS Docker workflow. Gazebo GUI forwarding, PX4 UDP networking, and QGroundControl connections through Docker Desktop are untested.

For local development, run Ubuntu 24.04 in a Linux VM. Install Docker Engine and QGroundControl inside that VM, then follow the [Linux setup](../setup/LINUX.md).

If you get this workflow running on macOS, document the setup steps and any platform-specific changes in this file.
