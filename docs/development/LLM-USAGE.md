# LLM Use in This Project

LLMs are part of software development today. Their use cannot be prevented in this project. Contributors may use them for assistance. LLM assistance does not replace understanding, review, or project standards.

## Required practice

- Vibe coding is prohibited in this project.
- Do not use an LLM as a shortcut around learning the project architecture or understanding the code being changed.
- Use time saved through LLM assistance to study the project architecture and research the purpose and behavior of the code.
- Reviewing LLM-generated code is required. Submitting or pushing code without reviewing it is unacceptable. Review correctness, behavior, safety, and adherence to the [project coding standards](../../CONTRIBUTING.md).
- LLM-generated code that does not adhere to the project coding standards is unacceptable. Do not submit it.
- Pushing code you cannot reasonably explain is unacceptable. Be prepared to explain its purpose, behavior, and safety implications.
- Apply the same standards and review requirements to LLM-generated and human-written code.

## Real hardware safety

C++ is difficult to work with. The desire to use LLMs for C++ development is understandable. This project targets real hardware on a real drone. A software failure can cause a drone crash, property damage, or physical injury. Running LLM-generated code that nobody reviewed or understands could cause a drone crash and injure someone. This outcome is unacceptable. Contributors must verify and understand code before running it on the drone.
